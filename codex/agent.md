# Instruções para futuras sessões do Codex

1. Leia primeiro `/agente.md`.
2. Trabalhe em etapas pequenas.
3. Não faça grandes refactors sem necessidade.
4. Não generalize o escopo: priorize Solidity/EVM, Vaults e Oracles.
5. Execute os testes relevantes após cada mudança.
6. Atualize `/agente.md` depois de cada etapa importante.
7. Nunca armazene API keys, tokens, passwords, secrets, private keys ou seed phrases.
8. Não modifique outros projetos no SSD Sherlock.
9. Prefira análise determinística antes de LLM e envie somente contexto mínimo.
10. Minimize tokens e contexto.
11. Não invente resultados: registre apenas verificações realmente executadas.
12. Uma vulnerabilidade só é válida após reprodução.
13. Não execute exploração em produção nem envie transações ofensivas para contratos reais.
